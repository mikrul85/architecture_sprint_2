# pymongo-api

## Как запустить

Запускаем mongodb и приложение

```shell
docker compose up -d
```

Делаем инициализацию сервера конфигурации, шардов с репликами, роутера, редис. Наполняем роутер данными. Получаем результат хранения данных каждой реплики каждого шарда.

```shell
./scripts/mongo-init.sh
```

## Как проверить

### Если вы запускаете проект на локальной машине

Откройте в браузере http://localhost:8080/docs
Сделайте несколько раз Get запрос метода /<collection_name>/users
collection_name - helloDoc
Каждый последующий запрос занимает менее 100мс

### Если вы запускаете проект на предоставленной виртуальной машине

Узнать белый ip виртуальной машины

```shell
curl --silent http://ifconfig.me
```

Откройте в браузере http://<ip виртуальной машины>:8080
